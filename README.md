# 高校 Wiki 目录

一个只做导航的静态目录站：登记中国各高校由学生、校友自发运营的 Wiki 站点入口，然后把读者送到原始站点去。

**本站不收录、不复制、不改写任何学校 Wiki 的正文内容。**

线上地址：<https://eryuemu.github.io/college-wiki-hub/>

## 每个条目记录什么

只记录可核查的事实：学校名、站点地址、搭建平台、地址可达状态、最近一次人工核查日期。

不记录：正文摘录、站内截图、站长个人信息。

不评价：某个 Wiki 写得好不好、信息准不准、立场如何。要判断请自己打开它。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| `可访问` | 核查时能打开，并确认页面确实是这所学校的站点 |
| `待核实` | 核查无法确证，**不代表站点已下线** |
| `已失效` | 核查时确认无法访问 |
| `停更` | 站点可访问，但源码仓库长期无提交 |

核查方式：抓取首页，核对标题与校名关键词是否真实出现；对单页应用额外核对它的数据端点。仅凭 HTTP 200 不算通过——静态托管的 404 页与空壳首页同样返回 200。

失效条目只改状态、保留记录，不删除。

## 如果你是某个被登记站点的负责人

要求移除条目、修改描述或隐藏某个字段，直接提 [issue](https://github.com/eryuemu/college-wiki-hub/issues) 即可，**无需说明理由**。确认收到后 7 天内处理。

本站从未逐一征询各站点负责人意见。这是发起者的判断：登记公开站点的名称与网址本身不构成对内容的复制。若这个前提让你不适，请按上面的方式提出，我们会照办。

## 维护带宽

条目由维护者利用课余时间**不定期**人工核查，不做实时更新，也不为响应速度设定任何指标、周期或时间表。信息可能过期，请以各站点原始内容为准。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run dev        # 开发服务器，默认 http://localhost:4321/college-wiki-hub/
npm run build      # 构建静态产物到 dist/
npm run preview    # 预览构建结果
```

注意访问地址末尾的 `/college-wiki-hub/` 不能省略，GitHub Pages 项目站点都带这一层。

## 技术栈

[Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/) 官方模板，无自定义组件，无后端，无数据库。目录内容就是 `src/content/docs/wikis.md` 里的 Markdown 表格，任何人都能直接改并提 PR。
